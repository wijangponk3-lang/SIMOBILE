# SIMOBILE - Aplikasi Manajemen & Transaksi Mobile

Aplikasi Sistem Informasi Mobile (SIMOBILE) dikembangkan menggunakan Ionic Framework dan Angular. Aplikasi ini dirancang untuk memenuhi kriteria Tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Aplikasi Bergerak.

---

## 🚀 Fitur Utama

- **Dashboard Interaktif:** Menampilkan statistik ringkasan total produk, total transaksi, dan produk terlaris secara *real-time*[cite: 2].
- **Manajemen Produk:** Daftar produk dengan fungsi pencarian *real-time*, filter kategori, serta Form Tambah/Edit Produk menggunakan *Reactive Form* dengan validasi ketat[cite: 2, 3].
- **Detail Produk:** Halaman detail untuk melihat rincian stok, harga jual, harga beli, dan status ketersediaan barang[cite: 2].
- **Keranjang & Transaksi:** Perhitungan total belanja otomatis, konfirmasi pesanan, dan pencatatan riwayat transaksi[cite: 3].
- **Navigasi & Tema:** Navigasi ganda (Tab Bar & Side Drawer Menu) serta dukungan kustomisasi tema dan Mode Gelap (Dark Mode)[cite: 2, 3].

---

## 🛠️ Teknologi yang Digunakan

- **Framework:** Ionic Framework (Angular)
- **Bahasa Pemrograman:** TypeScript, HTML, SCSS
- **Arsitektur Data:** Angular Service & Local Data Handling (tanpa database eksternal)[cite: 1, 3]
